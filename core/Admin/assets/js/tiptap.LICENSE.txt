tiptap.js — bundle vendorizado do editor richtext do admin do Velk
====================================================================

O QUE É
  Um único arquivo ESM (tiptap.js) com o editor Tiptap empacotado — usado
  pelo campo `richtext` do admin (core/Admin/assets/js/admin.js importa dele).
  Servido localmente por AssetController::js() em /admin/__static/js/tiptap.js.
  NÃO há CDN nem dependência de rede em runtime: o admin funciona offline.

VERSÃO
  Tiptap 2.27.2. Pacotes de entrada empacotados neste bundle:
    @tiptap/core@2.27.2
    @tiptap/starter-kit@2.27.2      (bold, italic, strike, heading, listas,
                                     parágrafo, blockquote, code, hard-break,
                                     history/undo-redo, horizontal-rule, …)
    @tiptap/extension-link@2.27.2
    @tiptap/extension-image@2.27.2  (embutido para a feature de imagem no
                                     conteúdo; exportado como `Image`)
    @tiptap/extension-table@2.27.2         (tabela — colunas redimensionáveis)
    @tiptap/extension-table-row@2.27.2
    @tiptap/extension-table-cell@2.27.2
    @tiptap/extension-table-header@2.27.2
  Mais as dependências transitivas (prosemirror-*), inlinadas no arquivo.

SÍMBOLOS EXPORTADOS
  Editor, StarterKit, Link, Image, Table, TableRow, TableCell, TableHeader,
  Node, mergeAttributes
  (Node e mergeAttributes, do @tiptap/core, permitem definir extensões
   customizadas no próprio admin.js — ex.: o node Figure de imagem com
   legenda — sem novo rebuild.)

COMO REGERAR (fora do repositório do Velk — nenhum toolchain vive no core)
  Num diretório qualquer FORA deste repo, com Node instalado:

    npm init -y
    npm install @tiptap/core@2 @tiptap/starter-kit@2 \
                @tiptap/extension-link@2 @tiptap/extension-image@2 \
                @tiptap/extension-table@2 @tiptap/extension-table-row@2 \
                @tiptap/extension-table-cell@2 @tiptap/extension-table-header@2 \
                esbuild

    # entry.js:
    #   export { Editor, Node, mergeAttributes } from '@tiptap/core';
    #   export { default as StarterKit } from '@tiptap/starter-kit';
    #   export { default as Link } from '@tiptap/extension-link';
    #   export { default as Image } from '@tiptap/extension-image';
    #   export { default as Table } from '@tiptap/extension-table';
    #   export { default as TableRow } from '@tiptap/extension-table-row';
    #   export { default as TableCell } from '@tiptap/extension-table-cell';
    #   export { default as TableHeader } from '@tiptap/extension-table-header';

    npx esbuild entry.js --bundle --format=esm --minify --outfile=tiptap.js

  Depois copie o tiptap.js gerado para core/Admin/assets/js/ e DÊ BUMP no
  `?v=` do import em admin.js (ex.: './tiptap.js?v=2.27.2-3'). O
  AssetController serve com cache de 24h sem revalidação — sem o bump,
  browsers seguram o bundle antigo e um admin.js novo importando exports
  novos mata o módulo inteiro até expirar. Para atualizar a versão do
  Tiptap, repita este processo (idealmente pinando as versões exatas) e
  substitua o arquivo. O node_modules/esbuild NUNCA entram neste repositório.
